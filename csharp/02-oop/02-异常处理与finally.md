# 异常处理与 finally

> 摸底第 18 题补漏：finally 的关键点是「**无论是否抛出异常都会执行**」，你当时只写了「最终需要执行的一步」。

## ① 概念总结（用自己的话回答）

- try / catch / finally 各自的作用是什么？
- finally 在什么情况下执行？什么极端情况下不执行？（提示：进程被杀、StackOverflow 等）
- 抛出异常后，代码的执行流程是怎样的（try 中抛异常后，后面的代码还执行吗）？
- 加分思考：什么时候应该捕获异常，什么时候应该让异常继续向上抛？

## ② 最小可运行示例

- [ ] 写一个 demo：try 中抛异常 → catch 捕获并打印 → finally 释放资源
- [ ] 实验：在 catch 里 return，观察 finally 是否还会执行（把结论写下来）
