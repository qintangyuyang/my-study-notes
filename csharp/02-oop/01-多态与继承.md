# 继承与多态

> 摸底第 14 题纠错：你把「多态」答成了「继承」。
> - **继承** = 子类复用父类的成员（怪物继承基类、各有属性 → 这是继承）
> - **多态** = 父类引用指向子类对象时，调用的是**子类**的方法（Animal a = new Dog(); a.Speak() 调 Dog 的实现）

## ① 概念总结（用自己的话回答）

- 继承解决什么问题？（代码复用、is-a 关系）
- 多态解决什么问题？（同一基类引用，行为随对象不同而不同）
- virtual / override / base 分别是什么？
- 为什么 `Animal a = new Dog(); a.Speak();` 会调用 Dog 的 Speak？
