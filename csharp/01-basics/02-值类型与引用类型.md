# 值类型与引用类型、栈与堆

> 待填写：用**自己的话**完成三件套。
> 纠错点（摸底第 8 题）：引用类型变量**本身**存储在栈上，只有实例在堆上。你当时答「栈，堆，堆」——第二空应为「栈」。

## ① 概念总结（用自己的话回答）

- C# 中哪些是值类型？哪些是引用类型？
- 值类型变量存储在哪？引用类型变量本身存储在哪？new 出来的实例存储在哪？
- string 是哪种类型？它有什么特殊之处？（提示：内容不可变）
  - **值类型：int、float、double、bool、char、enum、struct；引用类型：class、数组、List、string、委托、接口、object**
  - **值类型变量直接存在栈上；引用类型变量本身存在栈上（存的是地址）；`new` 出来的实例存在堆上**
  - **string 是引用类型，但内容不可变：任何「修改」操作都会创建新字符串对象，原对象不变。正因不可变，它用起来像值类型，最容易混淆**

## ② 最小可运行示例

- [ ] 写一个 demo：声明 int、bool、自定义 struct、自定义 class 各一个；把它们赋值给另一个变量后，修改其中一个，观察另一个变不变（值类型复制值，引用类型复制引用）
- [ ] 实验：两个引用类型变量指向同一个实例时，通过一个变量修改实例，另一个变量能看到变化吗？
  - **代码：`csharp/exercises/week01/ValueRefDemo.cs`**
  - **结果：`int: a=10, b=20`；`struct: s1.X=1, s2.X=99`；`class: c1.X=99, c2.X=99`**
  - **结论：值类型赋值复制值本身，改副本不影响原变量；引用类型赋值复制地址，两个变量共享同一个堆上实例**

## ③ 踩坑记录

| 坑 | 原因 | 解决 |
|---|---|---|
| 以为 class 实例赋给新变量后是两个独立对象，结果改一个另一个也变 | 引用类型赋值只复制栈上的地址，不复制堆上的实例 | 需要独立副本时显式 new 一份或写 Clone 逻辑。 |
