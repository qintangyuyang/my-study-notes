# my-study-notes

记录我的 Unity / C# 学习历程（初级 → 中级，24 周）。

## 目录结构

| 目录 | 内容 |
|---|---|
| `log/` | 每周学习日志（周记、踩坑、复盘） |
| `csharp/` | C# 笔记（basics / oop）与每周代码练习 |
| `unity/` | Unity 知识点笔记 |
| `patterns/` | 设计模式与游戏架构 |
| `projects/` | 项目复盘（附 Unity 工程仓库链接） |
| `resources/` | 学习资源清单 |

## 约定

- 笔记三件套：概念总结（自己的话）→ 最小可运行示例 → 踩坑记录
- Unity 练习工程放独立仓库，本仓库只放笔记与代码片段
- 本地私有文件（学习计划、摸底测试等）已通过 `.gitignore` 排除，不会上传到 GitHub
