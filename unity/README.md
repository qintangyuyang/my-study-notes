# Unity 学习笔记（unity/）

- `Unity-知识点笔记.md`：**知识手册**，按主题分章（输入 / 移动 / 碰撞 / UI …），新学的 Unity 知识点追加到对应章节
- `practice/`：每周练习的脚本与场景搭建说明，按 `weekNN` 分目录

## Unity 工程放哪里

**独立仓库**：`D:\AA-Learning\unity-lab`（新建 Unity 2D 工程后在此 `git init`）。
笔记仓库只放笔记和代码片段，不放整个 Unity 工程——`Library/`、`Temp/` 这些体积大且随时重建。

## 约定

- 笔记只记**知识点**：概念、代码示例、对比表、常见坑
- 学习过程、每日记录、复盘写在 `log/` 周记里
- 每个主题章节末尾维护一张「常见坑」表
- 练习脚本先在笔记仓库写好骨架（`practice/weekNN/`），再拷进 Unity 工程的 `Assets/Scripts/`
